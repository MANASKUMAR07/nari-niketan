1. Executive Summary & Core Capabilities

Nari Niketan is an enterprise-grade, multi-vendor serverless E-Commerce web application and Progressive Web App (PWA) tailored for the Indian ethnic fashion market. The platform connects shoppers with authentic ethnic apparel (Sarees, Suits, Lehengas, Kurtas, and Dupattas) while empowering independent artisans and vendors through a dedicated Seller Portal.

Serverless Cloud-Native Architecture

Built with zero server maintenance overhead, Nari Niketan leverages Google Cloud Firestore and Firebase Hosting. The architecture effortlessly scales from zero to 100,000+ simultaneous shoppers with sub-100ms global query speeds, automated SSL certificates, and zero infrastructure management costs.

4. Technology Stack & Architectural Rationale

✅ Frontend: Semantic HTML5 + Vanilla CSS3 + ES6+ JS

  • 0ms Hydration Overhead: Renders immediately on mobile devices without heavy framework loading.
  • Zero Build Dependency: No Webpack or Vite build steps required for deployment.
  • Ultra-Low Data Consumption: Lightweight assets optimized for 3G/4G Indian networks.
  • Native Longevity: Built on evergreen web standards that won't break with third-party framework updates.

✅ Backend: Google Cloud Firestore (Serverless NoSQL)

  • Direct Browser Connection: Eliminates the need for custom Express/Node.js API servers.
  • Real-Time Synchronization: Live order updates and inventory changes push instantaneously to clients.
  • Declarative Security: Access control enforced directly on Google hardware via firestore.rules.
  • Automatic Scaling: Scales seamlessly from 0 to 100,000+ active users with zero ops overhead.

6. Dual-Pricing, PWA & Component Map

6.1 Dual-Pricing Engine (MRP vs Selling Price)

To maximize shopper conversion, Nari Niketan implements a transparent pricing structure:

  • price (MRP): Maximum Retail Price, displayed with a strike-through (e.g. ₹3,999).
  • salePrice: Actual discounted price charged at checkout (e.g. ₹1,999).
  • % OFF Badge: Dynamically computed in JavaScript: Math.round(((price - salePrice) / price) * 100)% OFF.

6.2 Progressive Web App (PWA) Architecture

  • Service Worker (sw.js): Intercepts network requests and caches core stylesheets, icons, and scripts for offline access.
  • Web Manifest (manifest.webmanifest): Defines standalone app experience with high-resolution brand icons and splash screens.
  • Custom Install Prompt (js/pwa-install.js): Renders a branded modal guiding users on installing the app on Android and iOS.

7. Authentication & RBAC Security Engine

Security is enforced on Google's cloud infrastructure using server-verified JSON Web Tokens (JWT) and Firestore Security Rules.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isAuthenticated() { return request.auth != null; }

    // Hardcoded Super-Owner Check from Google Auth Token
    function isOwner() {
      return isAuthenticated() && (
        request.auth.token.email == 'manasku2007@gmail.com' ||
        request.auth.token.email == 'nariniketan07@gmail.com'
      );
    }

    // Admin Verification (Owner or approved in /users)
    function isAdmin() {
      return isOwner() ||
        (isAuthenticated() &&
          exists(/databases/$(database)/documents/users/$(request.auth.uid)) &&
          get(/databases/$(database)/documents/users/$(request.auth.uid)).data.isAdmin == true);
    }

    // Approved Seller Check
    function isSeller() {
      return isAuthenticated() &&
        exists(/databases/$(database)/documents/users/$(request.auth.uid)) &&
        (get(/databases/$(database)/documents/users/$(request.auth.uid)).data.isSeller == true ||
         get(/databases/$(database)/documents/users/$(request.auth.uid)).data.sellerStatus == 'approved');
    }

    match /products/{productId} {
      allow read: if true;
      allow create: if isAdmin() || (isSeller() && request.resource.data.sellerId == request.auth.uid);
      allow update: if isAdmin() || (isSeller() && resource.data.sellerId == request.auth.uid);
      allow delete: if isAdmin() || (isSeller() && resource.data.sellerId == request.auth.uid);
    }

    match /orders/{orderId} {
      allow read: if isAdmin() ||
        (isAuthenticated() && resource.data.userId == request.auth.uid) ||
        (isSeller() && resource.data.keys().hasAll(['sellerIds']) && request.auth.uid in resource.data.sellerIds);
      allow create: if isAuthenticated() && request.resource.data.userId == request.auth.uid;
      allow update: if isAdmin() ||
        (isAuthenticated() && resource.data.userId == request.auth.uid && (
          request.resource.data.status == "Cancelled" ||
          request.resource.data.status == "Return Requested"
        ));
      allow delete: if isAdmin();
    }

    match /users/{userId} {
      allow read: if isAdmin() || (isAuthenticated() && request.auth.uid == userId);
      allow create: if isAuthenticated() && request.auth.uid == userId;
      allow update: if isAdmin() ||
        (isOwner() && request.auth.uid == userId) ||
        (isAuthenticated() && request.auth.uid == userId &&
          !request.resource.data.diff(resource.data).affectedKeys()
            .hasAny(['isAdmin', 'isSeller', 'sellerStatus']));
      allow delete: if isAdmin();
    }
  }
}
